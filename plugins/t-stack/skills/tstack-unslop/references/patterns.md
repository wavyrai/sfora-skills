# The patterns, with fixes

Each pattern has a fix and an example from the kind of text a team of agents writes.

## Words

**Stock AI words.** Additionally, crucial, delve, enhance, foster, garner, intricate, landscape, pivotal, robust, seamless, showcase, tapestry, testament, underscore, vibrant. Use the plain word, or say the fact.
- "This crucial fix seamlessly enhances the merge flow." → "The merge now waits for the running deploy."

**Inflated verbs for "is" and "has".** Serves as, stands as, boasts, features. Write "is" or "has".

**Fancy words for plain ones.** Utilize, leverage, facilitate, numerous, in the event that. Write use, use, help, many, if.

**Abstract metaphor nouns.** Substrate, vector, locus, nexus, paradigm, modality, north star, flywheel, endgame, bedrock, "surface" for an interface, "harness" or "scaffolding" used as metaphors. Name the real thing. A test harness is a real thing; "harness the power of" is not.

**Adverbs propping up a verb.** "Significantly improves" becomes the measured change. "Runs quickly" becomes the number.

## Sentences

**Superficial "-ing" tails.** "…, ensuring reliability", "…, highlighting the need for". Delete the tail, or make it a sentence with a fact.

**Vague attribution.** "It's widely believed", "experts say". Name the source or cut it.

**"Not just X, but Y".** State Y.

**Forced threes.** Use the number of items there are.

**Synonym cycling.** The card, the ticket, the task, the item in one paragraph. Pick one name and repeat it.

**False ranges.** "From planning to production" when the two ends aren't on one scale. List the things.

**Passive voice that hides the actor.** "The tests were run" → "the reviewer ran the tests at the head". Passive is fine when the actor doesn't matter.

**Dense sentences.** If you had to reread it, split it.

**Over-compression.** "Put fails → 409, retry block" → "If the put fails with a 409, read the blocks again and aim at the new id."

**Mannered phrasing.** Aphorisms, personified code ("the card holds the truth"), figurative verbs ("rides along"). Say it literally.

**Feeling instead of mechanism.** "The board feels much calmer now." What changed? "Follow-ups now go to Triage, not To do."

## Punctuation and format

**Em dashes.** Don't use them. End the sentence or use a comma.

**Colons that join clauses.** Fine before a list or an example. Not as a hinge in the middle of a sentence.

**Bold everywhere.** Bold the one thing the reader must not miss, not every name.

**Bold labels that repeat the line.** "**Performance:** Performance improved." Turn it into a sentence.

**Title Case Headings.** Use sentence case.

**Decorative emoji.** Remove them.

**Curly quotes.** Use straight quotes.

## Chat habits

**Chatbot phrases.** "Great question", "Certainly!", "Hope that clears it up", "Happy to dig into anything else". Delete.

**Flattery.** "You're absolutely right." Answer directly.

**Filler.** "In order to" → "to". "Due to the fact that" → "because". "It's worth noting that" → nothing.

**Stacked hedges.** "It could potentially be argued that it might" → "it may", or the fact.

**Generic endings.** "Exciting times ahead." State the next step or stop.

## The final test

For each sentence, ask what it tells the reader to do or know. If you can't restate it as an instruction, a fact or a number, cut it. A sentence that would fit word for word into some other project's text tells the reader nothing about this project.
